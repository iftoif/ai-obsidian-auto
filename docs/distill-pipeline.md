# 蒸馏管道

把 AI 聊天记录自动蒸馏成结构化知识。

## 管道分层

```txt
Raw 聊天记录（各工具 Chat Logs）
  ↓ 蒸馏（LLM 处理）
Wiki 层：
  Sources/   来源摘要（日期-标题.md）
  Concepts/  概念（什么是 X）
  Entities/  实体（工具/人/项目）
  Topics/    主题综述（跨来源）
Lessons 层：
  {工具}/Lessons/   工具特有经验
  Shared/Lessons/   跨工具经验
```

## 增量机制

```txt
1. 扫描 Chat Logs，对比状态文件（mtime:size 签名）
2. 只处理新增/修改的文件
3. 处理完更新状态
4. 下次跳过已处理的
```

## 蒸馏规则（prompt 要求）

- Raw 原文只读，不修改
- 过滤寒暄、测试、重复输出、失败调试过程
- 只保留：最终结论、已验证配置、决策、踩坑、可复用经验
- 已有主题增量合并去重，不重复建页
- 事实标注来源，敏感信息脱敏
- 新旧结论冲突：并列保留，标注来源/时间/失效原因（不覆盖旧结论）

## Fallback 链

```txt
主模型 → 降级模型1 → 降级模型2
失败检测基于输出内容特征（不是退出码）
```

## 图片处理

日志中的 `![[assets/...]]` 引用，蒸馏时用 vision 读取图片内容，关键信息总结成文字。

## 状态文件

```txt
distill_state.json：
{
  "files": {
    "Hermes/Chat Logs/2026-08-01.md": "1785955496000000000:77912"
  }
}
```

签名 = mtime_ns:size，用于判断文件是否变化。
